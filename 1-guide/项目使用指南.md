# DJI Cloud API 项目使用指南

## 项目概述

DJI Cloud API 是大疆创新提供的云端集成解决方案，主要解决开发者重复造轮子的问题。对于不需要深度定制APP的开发者，可以直接使用 DJI Pilot2 与第三方云平台通信，开发者可以专注于云服务接口的开发和实现。

**重要提醒**：该项目已于2025年4月10日终止维护，仅作为参考实现，不建议在生产环境中直接使用。

## 项目架构

### 技术栈
- **后端**：Spring Boot 2.7.12 + Java 11
- **数据库**：MySQL 8.0 + Redis
- **消息队列**：MQTT (Eclipse Mosquitto)
- **对象存储**：支持阿里云OSS、AWS S3、MinIO
- **前端**：Vue 3 + TypeScript + Vite
- **地图服务**：高德地图
- **直播流**：支持RTMP、RTSP、GB28181、WebRTC

### 项目结构
```
dji-api/
├── cloud-sdk/          # Cloud SDK核心库
├── sample/             # 示例应用
├── sql/                # 数据库脚本
├── api/                # Postman测试集合
└── 1-guide/            # 项目文档
```

## 快速开始

### 1. 数据库初始化

```sql
-- 创建数据库
CREATE DATABASE dji_cloud CHARACTER SET utf8mb4;

-- 导入数据库结构
mysql -u root -p dji_cloud < sql/cloud_sample.sql
```

- `wayline_job` - 航线任务表
- `media_file` - 媒体文件表
- `flight_area_file` - 飞行区域文件表
- 以及其他相关表结构

## 核心功能模块

### 1. 设备管理 (Device Management)

#### 主要功能
- 设备注册和绑定
- 设备状态监控
- 设备固件管理
- 设备日志收集

#### 关键接口
- `GET /api/v1/manage/devices` - 获取设备列表
- `POST /api/v1/manage/devices/bind` - 绑定设备
- `GET /api/v1/manage/devices/{device_sn}/status` - 获取设备状态

#### 实现示例
```java
@Service
public class DeviceServiceImpl extends AbstractDeviceService {
    
    @Override
    public void updateTopoOnline(String deviceSn, TopoOnlineReceiver receiver) {
        // 实现设备上线逻辑
        log.info("设备上线: {}", deviceSn);
    }
}
```

### 2. 飞行控制 (Flight Control)

#### 主要功能
- 飞行权限控制
- 飞行指令下发
- 实时状态监控
- 紧急停止

#### 控制方法
- `flight_authority_grab` - 获取飞行权限
- `fly_to_point` - 飞向指定点
- `drone_emergency_stop` - 紧急停止
- `takeoff_to_point` - 起飞到指定点

#### 实现示例
```java
@Service
public class ControlServiceImpl implements IControlService {
    
    @Autowired
    private SDKControlService sdkControlService;
    
    public void flyToPoint(String deviceSn, FlyToPointParam param) {
        sdkControlService.flightAuthorityGrab(deviceSn);
        sdkControlService.flyToPoint(deviceSn, param);
    }
}
```

### 3. 载荷控制 (Payload Control)

#### 主要功能
- 相机控制
- 云台控制
- 拍照录像
- 参数设置

#### 控制方法
- `camera_photo_take` - 拍照
- `camera_recording_start` - 开始录像
- `camera_aim` - 相机瞄准
- `gimbal_reset` - 云台复位

### 4. 航线管理 (Wayline Management)

#### 主要功能
- 航线文件管理
- 任务创建和执行
- 任务状态监控
- 媒体文件管理

#### 关键接口
- `POST /api/v1/wayline/files` - 上传航线文件
- `POST /api/v1/wayline/jobs` - 创建任务
- `GET /api/v1/wayline/jobs/{job_id}/status` - 获取任务状态

### 5. 地图服务 (Map Service)

#### 主要功能
- 地图显示
- 飞行区域管理
- 元素绘制
- 坐标转换

#### 支持的地图类型
- 高德地图
- 自定义地图图层

### 6. 直播流 (Live Stream)

#### 支持的协议
- **RTMP**: 实时消息传输协议
- **RTSP**: 实时流传输协议
- **GB28181**: 国标协议
- **WebRTC**: 网页实时通信

#### 配置示例
```yaml
livestream:
  url:
    rtmp:
      url: rtmp://192.168.1.1/live/
    rtsp:
      username: admin
      password: password
      port: 8554
```

## Cloud SDK 集成指南

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.dji</groupId>
    <artifactId>cloud-sdk</artifactId>
    <version>1.0.3</version>
</dependency>
```

### 2. 组件扫描配置

```java
@SpringBootApplication
@ComponentScan("com.dji")
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### 3. MQTT连接配置

```java
@Configuration
public class MqttConfig {
    
    @Bean
    public MqttConnectOptions mqttConnectOptions() {
        MqttConnectOptions options = new MqttConnectOptions();
        options.setServerURIs(new String[]{"tcp://localhost:1883"});
        options.setUserName("JavaServer");
        options.setPassword("123456".toCharArray());
        return options;
    }
    
    @Bean
    public MqttPahoClientFactory mqttClientFactory() {
        DefaultMqttPahoClientFactory factory = new DefaultMqttPahoClientFactory();
        factory.setConnectionOptions(mqttConnectOptions());
        return factory;
    }
}
```

### 4. 实现SDK方法

```java
@Service
public class SDKDeviceService extends AbstractDeviceService {
    
    @Override
    public void updateTopoOnline(String deviceSn, TopoOnlineReceiver receiver) {
        // 实现设备上线逻辑
    }
    
    @Override
    public void updateTopoOffline(String deviceSn, TopoOfflineReceiver receiver) {
        // 实现设备下线逻辑
    }
}
```

### 5. 调用SDK方法

```java
@Service
public class BusinessService {
    
    @Autowired
    private SDKWaylineService waylineService;
    
    public void createWaylineJob(String deviceSn, WaylineJobCreateParam param) {
        waylineService.waylineJobCreate(deviceSn, param);
    }
}
```

## 常见问题解决

### 1. 设备连接失败
- 检查MQTT服务器连接
- 确认设备网络配置
- 验证认证信息

### 2. 地图不显示
- 检查高德地图API Key
- 确认网络连接
- 检查浏览器控制台错误

### 3. 直播流无法播放
- 检查流媒体服务器配置
- 确认协议设置正确
- 验证网络连通性

### 4. 文件上传失败
- 检查对象存储配置
- 确认存储权限设置
- 验证文件大小限制
