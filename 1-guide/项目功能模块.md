# DJI Cloud API 项目功能模块

## 项目概述

DJI Cloud API 是大疆创新提供的云端集成解决方案，主要解决开发者重复造轮子的问题。对于不需要深度定制APP的开发者，可以直接使用 DJI Pilot2 与第三方云平台通信，开发者可以专注于云服务接口的开发和实现。

**重要提醒**：该项目已于2025年4月10日终止维护，仅作为参考实现，不建议在生产环境中直接使用。

## 技术架构

### 技术栈
- **后端**：Spring Boot 2.7.12 + Java 11
- **数据库**：MySQL 8.0 + Redis
- **消息队列**：MQTT (Eclipse Mosquitto)
- **对象存储**：支持阿里云OSS、AWS S3、MinIO
- **前端**：Vue 3 + TypeScript + Vite
- **地图服务**：高德地图
- **直播流**：支持RTMP、RTSP、GB28181、WebRTC

### 项目结构
```
dji-api/
├── cloud-sdk/          # Cloud SDK核心库
├── sample/             # 示例应用
├── sql/                # 数据库脚本
├── api/                # Postman测试集合
└── 1-guide/            # 项目文档
```

## 核心功能模块

### 1. 设备管理模块 (Device Management)

#### 主要功能
- **设备注册与绑定**：设备上线、下线状态管理
- **设备拓扑管理**：无人机、遥控器、机库、载荷设备关系管理
- **设备信息查询**：设备状态、固件版本、载荷信息查询
- **设备字典管理**：支持多种DJI设备型号识别
- **HMS健康管理**：设备健康状态监控和告警

#### 核心接口
- `GET /api/v1/manage/devices/{workspace_id}/devices` - 获取设备拓扑列表
- `POST /api/v1/manage/devices/{device_sn}/binding` - 绑定设备到工作空间
- `GET /api/v1/manage/devices/{workspace_id}/devices/{device_sn}` - 获取设备详情
- `GET /api/v1/manage/devices/{workspace_id}/devices/bound` - 获取已绑定设备列表

#### 数据库表
- `manage_device` - 设备基础信息表
- `manage_device_dictionary` - 设备型号字典表
- `manage_device_payload` - 设备载荷信息表
- `manage_device_hms` - 设备健康管理表
- `manage_device_firmware` - 设备固件信息表

### 2. 飞行控制模块 (Flight Control)

#### 主要功能
- **飞行权限控制**：获取/释放飞行控制权限
- **飞行指令下发**：飞向指定点、起飞到指定点
- **紧急停止**：飞行任务紧急停止
- **载荷控制**：相机控制、云台控制、拍照录像
- **远程调试**：机库远程调试功能

#### 核心接口
- `POST /api/v1/control/devices/{sn}/authority/flight` - 获取飞行权限
- `POST /api/v1/control/devices/{sn}/jobs/fly-to-point` - 飞向指定点
- `POST /api/v1/control/devices/{sn}/jobs/takeoff-to-point` - 起飞到指定点
- `DELETE /api/v1/control/devices/{sn}/jobs/fly-to-point` - 停止飞向指定点
- `POST /api/v1/control/devices/{sn}/jobs/{service_identifier}` - 远程调试

#### 控制方法
- `flight_authority_grab` - 获取飞行权限
- `payload_authority_grab` - 获取载荷控制权限
- `fly_to_point` - 飞向指定点
- `takeoff_to_point` - 起飞到指定点
- `camera_photo_take` - 拍照
- `camera_recording_start` - 开始录像

### 3. 航线管理模块 (Wayline Management)

#### 主要功能
- **航线文件管理**：KMZ文件上传、解析、存储
- **任务创建与执行**：航线任务创建、下发、执行
- **任务状态监控**：任务进度、状态实时监控
- **媒体文件关联**：任务执行产生的媒体文件管理
- **任务调度**：支持定时任务和立即执行

#### 核心接口
- `POST /api/v1/wayline/workspaces/{workspace_id}/waylines/file/upload` - 上传航线文件
- `POST /api/v1/wayline/workspaces/{workspace_id}/flight-tasks` - 创建飞行任务
- `GET /api/v1/wayline/workspaces/{workspace_id}/jobs` - 获取任务列表
- `DELETE /api/v1/wayline/workspaces/{workspace_id}/jobs` - 取消任务
- `DELETE /api/v1/wayline/workspaces/{workspace_id}/waylines/{wayline_id}` - 删除航线文件

#### 数据库表
- `wayline_file` - 航线文件信息表
- `wayline_job` - 航线任务信息表
- `manage_firmware_model` - 固件型号关联表

### 4. 媒体文件管理模块 (Media Management)

#### 主要功能
- **文件上传管理**：媒体文件上传、去重、存储
- **文件信息查询**：文件列表查询、详情查询
- **文件下载**：生成下载链接、文件下载
- **文件指纹管理**：基于文件指纹的重复检测
- **任务关联**：媒体文件与航线任务关联

#### 核心接口
- `GET /api/v1/media/files/{workspace_id}/files` - 获取媒体文件列表
- `GET /api/v1/media/files/{workspace_id}/file/{file_id}/url` - 获取文件下载链接
- `POST /api/v1/media/workspaces/{workspace_id}/files/fast-upload` - 快速上传检查
- `POST /api/v1/media/workspaces/{workspace_id}/files/upload-callback` - 上传回调

#### 数据库表
- `media_file` - 媒体文件信息表

### 5. 地图服务模块 (Map Service)

#### 主要功能
- **地图元素管理**：点、线、面等地图元素绘制和管理
- **元素分组管理**：地图元素分组、层级管理
- **坐标管理**：地理坐标存储和转换
- **飞行区域管理**：禁飞区、限飞区管理
- **实时同步**：地图元素实时同步到Pilot

#### 核心接口
- `GET /api/v1/map/workspaces/{workspace_id}/element-groups/{group_id}/elements` - 获取地图元素
- `POST /api/v1/map/workspaces/{workspace_id}/element-groups/{group_id}/elements` - 创建地图元素
- `PUT /api/v1/map/workspaces/{workspace_id}/elements/{element_id}` - 更新地图元素
- `DELETE /api/v1/map/workspaces/{workspace_id}/elements/{element_id}` - 删除地图元素

#### 数据库表
- `map_group` - 地图元素分组表
- `map_group_element` - 地图元素表
- `map_element_coordinate` - 地图元素坐标表
- `flight_area_file` - 飞行区域文件表
- `flight_area_property` - 飞行区域属性表
- `device_flight_area` - 设备飞行区域关联表

### 6. 用户与工作空间管理模块 (User & Workspace)

#### 主要功能
- **用户管理**：用户注册、登录、权限管理
- **工作空间管理**：工作空间创建、配置、绑定码管理
- **JWT认证**：基于JWT的用户认证和授权
- **MQTT认证**：设备MQTT连接认证

#### 核心接口
- `POST /api/v1/manage/users/login` - 用户登录
- `GET /api/v1/manage/workspaces` - 获取工作空间列表
- `POST /api/v1/manage/workspaces` - 创建工作空间

#### 数据库表
- `manage_user` - 用户信息表
- `manage_workspace` - 工作空间表

### 7. 设备日志管理模块 (Device Logs)

#### 主要功能
- **日志收集**：设备日志文件收集和管理
- **日志上传**：日志文件上传到云端存储
- **日志索引**：日志文件索引和查询
- **日志分析**：日志文件分析和处理

#### 核心接口
- `POST /api/v1/manage/devices/{device_sn}/logs` - 创建日志收集任务
- `GET /api/v1/manage/devices/{device_sn}/logs` - 获取日志任务列表
- `GET /api/v1/manage/devices/{device_sn}/logs/{logs_id}` - 获取日志任务详情

#### 数据库表
- `manage_device_logs` - 设备日志任务表
- `logs_file` - 日志文件信息表
- `logs_file_index` - 日志文件索引表

### 8. 固件升级模块 (Firmware Upgrade)

#### 主要功能
- **固件管理**：固件文件上传、版本管理
- **升级任务**：固件升级任务创建和执行
- **升级进度**：升级进度实时监控
- **设备兼容性**：固件与设备型号兼容性检查

#### 核心接口
- `POST /api/v1/manage/devices/firmware` - 上传固件文件
- `GET /api/v1/manage/devices/firmware` - 获取固件列表
- `POST /api/v1/manage/devices/{device_sn}/firmware/upgrade` - 创建升级任务

#### 数据库表
- `manage_device_firmware` - 固件文件信息表
- `manage_firmware_model` - 固件型号关联表

### 9. 直播流模块 (Live Stream)

#### 主要功能
- **多协议支持**：RTMP、RTSP、GB28181、WebRTC
- **流媒体管理**：直播流创建、配置、管理
- **实时推流**：设备实时视频流推送
- **流媒体播放**：Web端直播流播放

#### 核心接口
- `POST /api/v1/manage/devices/{device_sn}/livestream` - 创建直播流
- `GET /api/v1/manage/devices/{device_sn}/livestream` - 获取直播流列表
- `DELETE /api/v1/manage/devices/{device_sn}/livestream/{stream_id}` - 停止直播流

### 10. 存储服务模块 (Storage Service)

#### 主要功能
- **多存储支持**：阿里云OSS、AWS S3、MinIO
- **文件存储**：文件上传、下载、管理
- **临时凭证**：STS临时访问凭证生成
- **存储配置**：存储服务配置和管理

#### 核心接口
- `GET /api/v1/storage/workspaces/{workspace_id}/files/{file_id}/url` - 获取文件访问URL
- `POST /api/v1/storage/workspaces/{workspace_id}/files/upload` - 文件上传

## 总结

DJI Cloud API 项目提供了完整的无人机云端管理解决方案，涵盖了设备管理、飞行控制、航线管理、媒体文件管理、地图服务等核心功能模块。通过标准化的API接口和MQTT通信协议，实现了云端平台与DJI设备的无缝集成，为开发者提供了便捷的无人机应用开发平台。
