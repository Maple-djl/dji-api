# DJI API 项目功能模块

## 登录鉴权模块

### 概述
DJI API项目采用基于JWT（JSON Web Token）的登录鉴权机制，确保API访问的安全性和用户身份验证。

### 核心组件

#### 1. 登录控制器 (LoginController)
- **位置**: `com.dji.sample.manage.controller.LoginController`
- **功能**: 处理用户登录请求和Token刷新
- **主要接口**:
  - `POST /manage/api/v1/login` - 用户登录
  - `POST /manage/api/v1/token/refresh` - Token刷新

#### 2. 用户服务 (UserService)
- **位置**: `com.dji.sample.manage.service.impl.UserServiceImpl`
- **功能**: 实现用户登录验证逻辑
- **验证流程**:
  1. 验证用户名是否存在
  2. 验证用户类型是否匹配
  3. 验证密码是否正确
  4. 验证工作空间ID是否有效
  5. 生成JWT Token

#### 3. JWT工具类 (JwtUtil)
- **位置**: `com.dji.sample.common.util.JwtUtil`
- **功能**: JWT Token的创建、验证和解析
- **配置参数**:
  - `jwt.issuer`: DJI
  - `jwt.subject`: CloudApiSample
  - `jwt.secret`: CloudApiSample
  - `jwt.age`: 86400秒（24小时）

#### 4. 认证拦截器 (AuthInterceptor)
- **位置**: `com.dji.sample.component.AuthInterceptor`
- **功能**: 拦截HTTP请求，验证Token有效性
- **验证流程**:
  1. 检查请求头中的`x-auth-token`
  2. 验证Token格式和签名
  3. 解析Token中的用户信息
  4. 将用户信息存储到请求属性中

#### 5. 自定义声明 (CustomClaim)
- **位置**: `com.dji.sample.common.model.CustomClaim`
- **功能**: 存储JWT Token中的用户信息
- **包含字段**:
  - `id`: 用户ID
  - `username`: 用户名
  - `userType`: 用户类型（1: web; 2: pilot）
  - `workspaceId`: 工作空间ID

### 认证流程

#### 1. 用户登录流程
```
用户请求 → LoginController → UserService → 验证用户信息 → 生成JWT Token → 返回用户信息和Token
```

#### 2. API请求验证流程
```
API请求 → AuthInterceptor → 检查Token → 验证Token有效性 → 解析用户信息 → 继续处理请求
```

#### 3. WebSocket认证
- **位置**: `com.dji.sample.component.websocket.config.AuthPrincipalHandler`
- **功能**: WebSocket连接时的身份验证
- **验证方式**: 通过URL参数传递Token进行验证

### 配置说明

#### 1. 拦截器配置 (GlobalMVCConfigurer)
- **排除路径**:
  - `/manage/api/v1/login` - 登录接口
  - `/manage/api/v1/token/refresh` - Token刷新接口
  - `/swagger-ui.html` - Swagger文档
  - `/swagger-ui/**` - Swagger资源
  - `/v3/**` - OpenAPI规范
  - `/ui/**` - UI资源

#### 2. 数据库表结构
- **表名**: `manage_user`
- **主要字段**:
  - `user_id`: 用户唯一标识
  - `username`: 用户名
  - `password`: 密码
  - `workspace_id`: 工作空间ID
  - `user_type`: 用户类型
  - `mqtt_username`: MQTT用户名
  - `mqtt_password`: MQTT密码

### 安全特性

1. **Token过期机制**: Token默认24小时过期
2. **Token刷新**: 支持Token刷新机制
3. **用户类型验证**: 区分Web端和Pilot端用户
4. **工作空间隔离**: 基于工作空间的访问控制
5. **CORS支持**: 跨域请求支持

### 使用示例

#### 登录请求
```json
POST /manage/api/v1/login
{
    "username": "admin",
    "password": "password",
    "flag": 1
}
```

#### 响应示例
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "userId": "user-uuid",
        "username": "admin",
        "accessToken": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
        "workspaceId": "workspace-uuid",
        "mqttAddr": "mqtt://localhost:1883"
    }
}
```

#### API请求头
```
x-auth-token: eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
```

### 注意事项

1. **密码安全**: 当前实现使用明文密码比较，生产环境建议使用加密存储
2. **Token安全**: 建议使用更强的密钥和更短的过期时间
3. **HTTPS**: 生产环境建议使用HTTPS传输
4. **日志安全**: 避免在日志中记录敏感信息
